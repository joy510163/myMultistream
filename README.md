## 最新更新 V1.4.2

- **電競三區布局**：左側隊伍 A 多台直播、中央官方主控台一台、右側隊伍 B 多台直播。兩側各自保留完整 16:9，寬度不足時水平捲動，不裁切影片。
- **自由分組**：可為雙方隊伍命名、從未分配頻道加入任一隊、調整隊內順序、移回候補；一鍵交換隊名及全部隊員。
- **候補區**：底部切換「精簡列表」與「迷你預覽」兩種顯示方式；迷你預覽採用靜態卡片，不額外載入播放器。
- **效能**：隊伍直播沿用監看播放器數量上限，超額位置保留可操作佔位卡片；官方播放器獨立顯示。
- **儲存與相容**：賽事分組會隨個人清單、具名組合、JSON 備份與 Hash 分享保存。舊版只有左右各一人的賽事配置也能讀取。
- 一大多小模式、聊天室、通知、音訊選擇、臨時放大及原有資料管理功能保留。

> Twitch 的嵌入播放器有最小尺寸要求；三欄布局在一般螢幕可能需要水平捲動。影片自動播放、靜音和切換音訊仍受各平台及瀏覽器政策限制。

# MultiStream Hub

Twitch × YouTube 多直播觀看中心（GitHub Pages 靜態網站）。

**最新版本：V1.4.2（2026-10-16）**

網站：https://joy510163.github.io/myMultistream/

## V1.4.0 既有功能

- **獨立音訊來源選擇**：可以選擇主直播或已加入的監看直播作為預期音源；預設全體靜音，新版按鈕可以選擇單一音源。由於平台播放器限制，切換來源可能重新載入影片，不保證瀏覽器允許有聲自動播放，使用者手動解除 iframe 靜音也可能繞過本頁控制。
- **布局預設**：「一大多小」、「雙欄觀看」及「四視角監看」；切換後自動啟用同步監看播放器。四視角為主直播加上監看網格，受限於 iframe 最小尺寸，並不保證四格等大，窄視窗會自動退回堆疊布局。
- **臨時放大**：主直播及監看卡片均可開啟獨立放大視窗，可按 Esc 或關閉按鈕退出。放大視窗另行載入靜音播放器，原列表不被修改。

## V1.3.0 功能（保留）

- **JSON 備份與還原**：在「我的組合」下載包含個人觀看清單及具名組合的 JSON，匯入時可選「合併」或「取代」。合併保留目前個人觀看清單，遇到同名組合則保留本機版本；取代會覆蓋兩類資料，請先備份。
- **監看卡片排序**：使用拖曳或上下移動按鈕調整順序；重新整理後仍保留個人清單順序。具名組合需手動按「更新此組合」保存修改。
- **專注觀看模式**：保留觀看控制台與工具列，隱藏介紹、新增來源輸入列與頂部導覽列；可直接點「離開專注模式」。
- **播放效能上限**：在設定中控制同時啟用的監看播放器數（0、2、4、8、16）；其餘仍保留可切換的預覽卡片。預設 4 台監看播放器，不包含主畫面。此控制不代表能強制控制 YouTube/Twitch 畫質或保證自動播放。

## 原有功能

Twitch/YouTube 播放、可拖曳一大多小布局、聊天室獨立切換及 YouTube 主題設定、LocalStorage 清單、Hash 網址分享（三種匯入模式）、具名直播組合管理、通知淡入／淡出與連續訊息更新。

## 開發與部署

`npm install` 後執行 `npm run build`。使用 `.github/workflows/deploy.yml` 部署 GitHub Pages；儲存庫須使用 `myMultistream` 的路徑。

GitHub 更新路徑與測試指引見 [UPDATE_GUIDE.md](UPDATE_GUIDE.md)，歷史版本見 [CHANGELOG.md](CHANGELOG.md)。
