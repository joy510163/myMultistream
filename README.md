# MultiStream Hub · V1.2.0

**Twitch + YouTube 多直播觀看中心** · [開啟網站](https://joy510163.github.io/myMultistream/)

## 最新版本：V1.2.0 — 我的直播組合

- 新增「我的組合」：可命名、儲存、載入、更新、重新命名與刪除最多 30 組觀看配置。
- 每組保存頻道順序、主畫面與聊天室選擇；切換組合後可繼續編輯，**需明確點擊「更新此組合」才會覆寫具名快照**。
- 先載入任一組合，再按「分享組合」，即可使用既有 Hash 分享機制。
- 組合僅儲存在目前瀏覽器 LocalStorage，不會同步至其他裝置；清除網站資料可能遺失組合。

## 目前功能

- Twitch 與 YouTube 直播連結加入與管理
- 一大多小、拖曳調整、監看區網格與多台同步播放選項
- 聊天室獨立切換及 YouTube 深淺色模式
- 通知淡入／淡出，5 秒自動關閉，顯示中更新內容不重播淡入
- 本機清單保存、Hash 網址分享、三種匯入模式（暫時／合併／取代）
- 多組具名觀看配置管理

## 使用方式

1. 開啟網站、加入想看的直播。
2. 點右上角 **我的組合**，輸入名稱並按「儲存新組合」。
3. 「載入」某組會切換目前畫面；修改後若要保存到該組，按「更新此組合」。
4. 點「分享組合」複製目前配置連結；短網址與後端未包含在此版本。

```bash
npm install

```

## 注意事項

- GitHub Pages 不提供本機組合同步或資料庫。分享網址是快照，不會連動後續的修改。
- 若收到 Hash 分享，預設可以暫時開啟，不會自動覆寫自己的收藏組合。
- 多台直播的效能與 Twitch／YouTube 嵌入限制取決於瀏覽器、設備及平台。
- 版本歷史請見 [CHANGELOG.md](CHANGELOG.md)。
